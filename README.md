# ЛР3 — индивидуальная часть, вариант 13

Проект реализует **контейнер контроля системной избыточности (УБИ.166)** из ЛР1.

## Что делает проект
- читает эталонный список разрешённых и устаревших контейнеров из `config.json`;
- читает имитационный список реально запущенных контейнеров из `running_containers.json`;
- выявляет неразрешённые и устаревшие компоненты;
- формирует таблицу `output/results.csv`;
- строит графики `output/redundancy_monitor.png`;
- записывает результат проверки в `logs/system_redundancy.log`.

Использование имитационного списка предусмотрено техническим заданием ЛР1 для учебного запуска без Docker.

## Replit Secrets
Для демонстрации хранения интеграционных параметров создайте в разделе Secrets:
- `DOCKER_API_TOKEN`
- `MONITOR_ACCESS_KEY`

Значения не должны размещаться в исходном коде или конфигурационном файле.

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Shell-скрипт по заданию 4
```bash
chmod +x Ter-Sargsyan2.sh
./Ter-Sargsyan2.sh
```

## Задание 5 — «Изменения2»
Файл `running_containers_before_changes2.json` содержит исходный набор данных до изменения. Текущий `running_containers.json` содержит изменённые данные: добавлены `temp_worker` и `old_api`, чтобы продемонстрировать более выраженную системную избыточность.
